# KeePassBox

Give a script or agent its own KeePass vault. Use REST or MCP to add credentials, rotate the master password, set the cipher and Argon2 memory, and get the current TOTP code. The vault stays a `.kdbx` file you can open in KeePassXC.

| Run the Docker image and get a token | [Install KeePassBox](install.md) |
