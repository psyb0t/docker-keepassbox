# KeePassBox

Give a script or agent its own KeePass vault. Use REST or MCP to add credentials, rotate the master password, set the cipher and Argon2 memory, and get the next TOTP code. The vault stays a `.kdbx` file you can open in KeePassXC.

## Where to start

| Want to | Read |
| --- | --- |
| Run the Docker image and get a token | [Install KeePassBox](install.md) |
| Create vaults, change encryption, and manage entries | [REST API](api.md) |
| Give an agent its own vault and permissions | [MCP](mcp.md) |
